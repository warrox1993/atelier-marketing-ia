# Sources de données disponibles (fictives)

- Outil de gestion de portefeuille : contrats, primes, résiliations (mise à jour quotidienne).
- Outil de suivi des sinistres : dossiers ouverts, délais de traitement.
- Outil de facturation : factures émises, impayés, encaissements.
- Formulaire de satisfaction client : réponses mensuelles (taux de réponse d'environ 8 %).
- Pas de source pour : le coût d'acquisition d'un client, le temps passé par dossier.

Indicateurs demandés pour le comité : nombre de contrats, primes émises, taux de résiliation, délai moyen de traitement des sinistres, impayés à plus de 60 jours, satisfaction client, coût d'acquisition d'un client, charge de travail par gestionnaire.
