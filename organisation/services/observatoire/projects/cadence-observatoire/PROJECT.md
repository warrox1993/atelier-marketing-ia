# Cadence hebdomadaire de l'Observatoire

Projet de fond qui porte les routines de la semaine (veille le lundi, exploration le mercredi, arbitrage le jeudi,
édition le vendredi). Les routines sont importées en pause : elles ne déclenchent rien tant qu'un humain ne les
active pas.
